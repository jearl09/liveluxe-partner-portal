# Pre-go-live check — partners.liveluxe.au

Run on 19 Oct 2026 (UTC) against `main` at `b946063` plus the fixes below. Production stayed in Stage 1 throughout
(Stripe **test** keys, Hostaway writes **off**); on production only read-only checks and one smoke probe were made.
The full flow ran on the test environment (Supabase `adgvnmbkvydkonnpskzx`, Stripe test mode) on a local server.

## 1. Verdict

**Not ready for live Stripe keys yet.** The code is sound: build, 391 tests, isolation, lockout, double-approval and
refund checks pass, two new hard guards are in, and the full flow ran end to end on the test environment. It also
found and fixed one **money bug** (a counter-offer that lowered the total was still charged in full on approval).
But production is running an older commit with **no properties synced**, invoices carry **no ABN**, there is **no
alert channel** for payment-critical failures, booking **extensions could not be exercised** (Hostaway's live calendar
refused every range), and the live keys must go in together with the Hostaway write key: the new guard refuses every
approval otherwise. The ordered blockers are in section 4.
