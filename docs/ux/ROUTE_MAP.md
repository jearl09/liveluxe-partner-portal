# Route map — before the redesign (Phase 0, 14 Oct 2026)

Every page under `app/(portal)`, `app/(admin)` and `app/(marketing)`, with the role that reaches it, what it is
for, every user-triggerable action on it (the form or link and the route handler it posts to), the data it reads,
the architecture-spec section it implements, and whether it exists. **This is the scope of the redesign: every
action listed here must still be reachable afterwards and do the same thing.** Routes marked _missing_ are out of
scope (brief §1); the navigation is designed so they can slot in later.

Legend — Status: ✅ exists · ◐ partial · ✗ missing. Roles: PA partner_admin, PB partner_booker, PV partner_viewer,
PF partner_finance (role exists in the enum; no user yet), OPS livluxe_ops, FIN livluxe_finance, ADM livluxe_admin.
